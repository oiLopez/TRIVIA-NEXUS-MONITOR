# NEXUS MONITOR - Contrato CSV: status_ldom.csv

## Objetivo

O arquivo `status_ldom.csv` é a fonte de dados inicial utilizada pelo frontend do NEXUS MONITOR para renderizar o estado operacional do dashboard de alta disponibilidade.

Ele representa o estado atual de ILOMs, Control Domains, LDOMs, serviços hospedados e workstations físicas.
